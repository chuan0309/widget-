# widget-

iOS 液態玻璃風格的桌面 Demo（純 HTML / CSS / JS）：

- 玻璃質感的桌面小組件：時鐘、天氣、電量（手機＋耳機＋充電盒）、音樂
- 藍牙耳機靠近時跳出的配對彈窗，連線後動態島展開、電量 widget 會更新
- 可以切換桌布，看玻璃在不同底色下的效果

## 怎麼看

直接用瀏覽器（Chrome / Safari 效果最好）打開 `index.html` 就可以了。

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 畫面結構 |
| `style.css` | 玻璃效果、動畫（`.glass` 就是玻璃材質） |
| `script.js` | 時鐘、彈窗、連線流程 |
